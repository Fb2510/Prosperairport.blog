Clash 显示已连接却打不开网页？新手按这 6 步排查

阿旺2026-10-06— 次阅读
客户端教程

Clash 界面看起来在运行，节点旁边也有延迟数字，但浏览器仍然打不开需要代理访问的网站。遇到这种情况，可以先按下面的顺序检查。

本文面向 Clash 类客户端使用者，运行模式等说明参考 Mihomo 文档。不同客户端和内核的按钮名称、支持功能会有差别，请按你实际使用的版本操作。

1. 先确认电脑本身能上网

暂时关闭客户端里的系统代理；如果正在使用 TUN，也先暂停它。然后测试平时能直连的网站。

如果这些网站也打不开，先检查 Wi-Fi、网线和宽带。也可以连接手机热点做对比，看看故障是否只发生在家庭网络。

如果退出客户端后反而无法上网，检查系统是否仍保留了手动代理设置。关闭指向已退出客户端的代理后，再测试普通网页。

2. 确认订阅已加载并正在使用

导入订阅后，还要确认它已经成为当前配置。

检查节点列表是否出现、是否显示更新错误，以及机场套餐是否到期或流量用完。更新失败时，先检查链接是否复制完整，再对照服务商提供的客户端格式。

如果客户端提示不支持某种配置或协议，向服务商确认适配要求。不要把订阅链接上传到来历不明的转换网站。

3. 手动选一个节点，再实际访问网页

先选一个具体节点，不要只停留在策略组名称上。测试失败时，再换两三个节点对比。

延迟数字说明的是对应测试的结果，不能保证所有网站都可用。用浏览器打开一个你平时需要代理访问的网站，才更接近实际使用。

如果只有一条节点失败，先使用备选线路；如果所有节点都失败，再换网络测试，并查看机场公告。

4. 检查浏览器流量有没有交给客户端

在电脑上，启动客户端之后，还要确认代理入口已启用。使用系统代理时，浏览器通常会按系统设置发送流量；有独立代理设置的软件则需要另外检查。

可以先关闭重复运行的代理客户端或浏览器代理扩展，再测试。多个工具同时改变代理设置，容易让结果难以判断。

如果客户端有“连接”或“日志”页面，打开网页时观察有没有出现相应请求。看不到请求，可以先查代理入口；看得到失败请求，再根据错误继续查节点、规则或 DNS。部分连接显示可能不完整，仍需结合其他测试。

5. 看清规则、全局和直连模式

Mihomo 文档列出了三种运行模式：规则模式按规则匹配；全局模式使用 GLOBAL 策略组中选定的代理或策略；直连模式走直连。查看运行模式说明

日常使用可以按自己的需要采用规则模式。排查时，可以临时切到全局模式，确认 GLOBAL 组确实选中了一个可用节点，再访问同一个网站。

如果全局可以、规则模式不行，可以重点查看该网站命中了什么规则，以及对应策略组选中了什么。测试完成后，切回原来的日常设置。全局测试也有自己的策略组选择，不能仅凭模式切换就认定节点已经正常。

6. 最后再考虑 TUN 和 DNS

系统代理主要影响遵循该设置的软件。TUN 使用虚拟网络接口接管流量；实际接管范围取决于路由等配置。它适合排查部分不走系统代理的应用，也会增加需要检查的设置。查看 Mihomo TUN 配置说明

如果浏览器已经正常，只有某个应用不行，可以先看它是否支持单独设置代理；需要 TUN 时，再按所用客户端的文档启用，并确认所需服务和权限。

DNS 可以理解成“把网站名字查成地址”。如果日志反复出现域名解析失败，先恢复此前能用的 DNS 配置，或向服务商确认推荐设置。Mihomo 对网站域名和代理节点域名有相关解析配置，随机复制一段 DNS 配置可能引入新的问题。查看 DNS 配置说明

每次只改一项，改完测试同一个网页。没有改善就恢复原设置，再检查下一项。

求助时这样描述，处理会更快

准备客户端名称和版本、系统版本、故障开始时间、普通网页是否正常、换节点和换网络后的结果，再附上经过遮挡的错误信息。

不要发送完整订阅、节点密码或带凭据的二维码。把问题描述清楚，通常比连续重装客户端更容易找到原因。
