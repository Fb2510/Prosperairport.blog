软路由翻墙入门：先让全家正常上网，再排查代理故障

阿旺2026-10-06— 次阅读
软路由与排障

软路由的吸引力，是可以在路由器上集中处理网络，让家里的设备按统一规则访问。但设置过程中，普通上网和代理访问要分开验证，才能看清故障发生在哪里。

这篇以 OpenWrt 为例，解释基础接法和排查顺序。代理插件、订阅协议和设备网口不同，具体安装步骤要按对应项目文档操作。

先认识四个名字

  • WAN：软路由连接上游网络的一侧。
  • LAN：软路由连接家中设备的一侧。
  • 网关：设备把访问交出去的下一站。
  • DNS：帮助设备把网站名字查成地址的服务。

可以把软路由想成路口：先保证设备能走到路口、路口能通向外网，再检查哪些访问需要走代理。

新手可以从一套清楚的接法开始

已有普通路由器时，可以先把软路由接在它后面测试：

普通路由器 LAN → 软路由 WAN → 软路由 LAN → 测试电脑或无线 AP。

例如，上游路由器使用 192.168.1.1，软路由 LAN 可以使用 192.168.2.1；两边采用 /24 子网时，就属于不同网段。这只是示例，修改前要检查家里现有地址，避免冲突。

OpenWrt 的联网排查文档也提醒检查 LAN 与 WAN 地址范围是否冲突。更改 LAN 地址后，需要用新地址重新进入管理页面。查看官方联网排查说明

这种接法会多一层路由，涉及端口映射或部分游戏连接时可能需要额外处理。它适合先测试基础功能；如果准备让软路由直接承担主路由，还需确认运营商接入方式和设备要求。

基础配置按这个顺序做

1. 保存原配置

记录原路由器地址、接线方式和上网设置，再下载 OpenWrt 的配置备份。LuCI 中通常可以在“系统 → 备份/升级”找到生成备份的入口，具体名称随版本变化。查看 OpenWrt 备份说明

备份文件不等于完整系统镜像。代理插件是否包含额外配置，要按插件说明确认，并妥善保存订阅信息。

2. 接好 WAN 和 LAN

网口多的软路由，接口名称可能与机身标签不同。先在管理页面确认哪个口接上游、哪个口接电脑，别只凭接口编号猜。

接在已有路由器后面时，WAN 通常可以通过 DHCP 自动取得地址。直接连接运营商线路时，则按实际要求使用 DHCP、PPPoE 或其他方式。查看 OpenWrt 路由设备说明

3. 确认设备拿到正确地址

测试电脑应取得软路由 LAN 网段的地址，网关指向软路由 LAN 地址；采用由软路由提供 DNS 的配置时，DNS 也应与该配置一致。

在同一局域网内，避免两台设备未经协调同时分配地址。如果普通路由器作为软路由后面的无线 AP，按它的 AP 模式说明配置，让地址分配关系保持清楚。

OpenWrt 常用 Dnsmasq 提供 DNS 转发和 DHCP 地址分配。改完相关设置后，可以重新连接 Wi-Fi 或更新设备网络连接，再检查拿到的新设置。查看 DHCP 与 DNS 说明

4. 先验证普通上网，再配置代理

保持代理插件暂停，测试普通网页，确认网关、上游网络和基础 DNS 正常。

然后按插件文档导入适配订阅、选择节点和启用规则，使用同一台测试设备访问需要代理的网站。确认能用后，再让更多家庭设备接入。

全家突然断网，先这样检查

先暂停代理插件，测试普通网页。如果仍然不通，检查 WAN 状态、网线和上游路由器。

如果电脑也打不开软路由管理页面，先检查电脑地址、LAN 接线，以及管理地址是否已经修改。不要连续改 DNS 来处理所有问题，连不上管理页面时，问题可能还没有到域名解析这一步。

普通网页能打开，代理网站不行

依次检查订阅是否有效、是否选中了可用节点、规则是否把目标网站送往代理，以及插件日志里有没有连接或解析错误。

还可以在手机上用同一家机场单独测试。为了看清结果，暂时只保留一层代理，并尽量使用相同网络和节点。手机可用而软路由不可用时，重点比较配置和插件兼容性。

只有部分设备有问题

先比较正常设备与异常设备的网关、DNS 和客户端代理设置，再重新连接网络测试。

如果怀疑 IPv6，要确认异常设备是否通过另一条路径访问，以及插件是否处理了相关流量。可以做临时对比，记录结果后恢复设置；永久关闭 IPv6 不能替代查明原因。查看 OpenWrt IPv6 排障说明

留一条恢复上网的路

保存接线照片、管理地址和修改记录，每次只调整一项。出现问题时，先恢复此前能正常上网的基础配置，再继续检查代理。

求助时提供软路由型号、OpenWrt 与插件版本、简单接线图和错误信息。订阅链接、宽带账号及备份文件中的凭据要遮住。清楚的网络关系，比一大堆未经核对的参数更有帮助。
