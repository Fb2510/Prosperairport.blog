群里发来的代理安装包，怎样核对？

阿旺2026-11-14— 次阅读
客户端教程

群里有人发了一个 Clash 客户端安装包，你可以先用 SHA-256 核对它和项目发布的同名文件是否一致。SHA-256 可以理解成用文件内容算出来的一串指纹。只要官方发布页给出了对应指纹，在 Windows 上就能用 PowerShell 比对，安装包本身无需打开。微软的文件校验说明

先找到官方发布页上的同一份文件

以 Clash Verge Rev 为例，从项目的安装文档进入 GitHub 发布页，找到对应版本，展开 Assets（发布文件），核对文件名、系统架构和包类型。x64 与 arm64 是不同架构，普通安装包和带 fix_webview2 的安装包也各有自己的文件。发布页中对应文件旁的 sha256: 后面是一串 64 位十六进制字符，比较时只复制这串字符。项目安装说明 项目官方发布页

如果转发者同时发来了校验值，也要自己从项目官方入口找一遍。下载文件和校验值都来自同一条群消息时，两者吻合也只能说明文件和那条消息里给的数字吻合。

在 Windows 算出手里这份文件的校验值

  1. 在文件资源管理器里找到下载好的安装包，右键选择「复制文件地址」或「复制为路径」。如果菜单没有这项，也可以先查看文件所在的文件夹，再拼出完整路径。
  2. 打开 PowerShell，把下面的示例路径换成你的安装包路径，保留路径外的一对引号。-LiteralPath 会按你填写的路径找文件，文件名含空格也可以这样写。Get-FileHash 用法
Get-FileHash -LiteralPath 'C:\Downloads\Clash Verge_2.5.10_arm64-setup.exe' -Algorithm SHA256
  1. 找到结果中的 Hash 一栏，与发布页上的完整校验值逐字符比对。英文字母大小写可以忽略，开头和结尾相同还不够。上面的文件名来自项目发布页，只用来演示路径写法。你应按自己的系统和实际版本选包。项目官方发布页

看比较结果，再决定是否安装

  • 完全一致。 手里的文件与发布页给出的 SHA-256 相符。这个结果用于核对文件内容，软件的功能和权限仍要看项目说明。
  • 有任何一位不同。 先检查自己是否选错了版本、架构或变体。确认对照项无误后，从官方发布页重新下载并复核，原来的文件先别运行。单凭不一致还无法判断是下载损坏、文件拿错，还是内容被改过。微软的比对示例
  • 官方没给对应文件的校验值。 这份文件无法用上述方法和官方版本比对。想安装时，可以直接从项目官方渠道取得对应安装包。

资料核对日期为 2026 年 11 月 14 日。
